Sensor & device metadata

Sensor & device metadata#

Sensor and device metadata sit on a parallel axis to the experimental context hierarchy. Rather than repeating instrument information across every experiment or session record, these two tables capture device properties once and reference them by ID wherever needed.

The two tables operate on different time scales:

  • Device Registry. Static properties of each physical device unit. Filled once per device, reused across all studies.

  • Calibration Log. One record per calibration event per device. Updated whenever a device is recalibrated.

A third table, Sensor Application, captures per-session placement and configuration for each device. Because it describes what happened during a specific session, it lives in the session-level metadata schema under the Devices & sensor application group.
