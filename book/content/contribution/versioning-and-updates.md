# Versioning and updates

This document is designed as a living reference and may be updated periodically as the field develops. Updates may include corrections, expanded methodological guidance, additional references, or revised terminology.

Changes are tracked through the project repository so that earlier versions remain accessible. When significant revisions occur, a new version identifier is assigned to allow readers to distinguish between releases.

Researchers who rely on the document for methodological guidance are therefore encouraged to reference the specific version used in their work.
