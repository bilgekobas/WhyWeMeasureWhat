# COMMUNITY AND GOVERNANCE

This section describes how the resource is maintained, how contributions are handled, how versions are archived, and how the project should be cited.

The resource is maintained as an open, collaboratively extensible methodological reference intended to support clarity, comparability, and transparency in physiological measurements within thermal-environment research.

The pages below provide information on:

- project governance and community roles,
- contribution workflows,
- contributor recognition,
- citation and versioning,
- licensing and reuse,
- and project contact information.
